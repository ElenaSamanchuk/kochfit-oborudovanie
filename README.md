# Kochfit — оборудование

Одностраничный блок оборудования для встраивания на Тильду через iframe + GitHub Pages.

## Страница

https://elenasamanchuk.github.io/kochfit-oborudovanie/

## Вставка на Тильду

1. Откройте страницу в редакторе Тильды.
2. Добавьте блок **HTML-код** (T123).
3. Вставьте содержимое файла [`tilda-embed.html`](./tilda-embed.html).
4. Опубликуйте страницу Тильды.

Высота iframe подстраивается автоматически (в том числе на мобильных) через `postMessage`.

При открытии попапа:
- скролл страницы Тильды блокируется;
- затемнение покрывает весь сайт Тильды (не только iframe);
- оверлей и модалка позиционируются по видимой области экрана, а не по всей высоте iframe.

Важно: после обновления `tilda-embed.html` заново вставьте код в блок T123 на Тильде.

## Обновление контента

Замените `index.html` и запушьте в `main` — GitHub Pages обновится сам.
